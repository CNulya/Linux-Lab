## Блок 1: Создание Linux-проекта
1.1) Мы создали отдельную директорию для Linux-проекта. Внутри директории мы также
подготовили директории для других задач.

Разобрались с командами и их значениями:
- pwd: показывает путь к директории, внутри которой находимся;
- ls: показывает файлы внутри директории;
- ls -la: показывает файлы внутри директории (скрытые файлы) вместе с 
правами к этим файлам;
- cd: позволяет перейти в нужную директорию;
- mkdir: создает новую директорию.

1.2) Мы создали файл README.md, в котором будем фиксировать пройденные этапы.

Разобрались с командами и их значениями:
- ls -l: покажет содержимое внутри директории с правами;
- file <name>: показывает тип файла и формат его содержимого;
- stat <name>: показывает полную информацию о файле.
