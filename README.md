Мы создали практический репозиторий для изучения Linux. Здесь я буду записывать по 
изученным моментам в Linux, будем использовать этот файл, как шпаргалку.

## Блок 1: Создание Linux-проекта
1.1) Мы создали отдельную директорию для Linux-проекта. Внутри директории мы также
подготовили директории для других задач.

Разобрались с командами и их значениями:
- pwd: показывает путь к директории, внутри которой находимся;
- ls: показывает файлы внутри директории;
- ls -la: показывает файлы внутри директории (скрытые файлы) вместе с 
правами к этим файлам;
- cd: позволяет перейти в нужную директорию;
- mkdir: создает новую директорию.

1.2) Мы создали файл README.md, в котором будем фиксировать пройденные этапы.

Разобрались с командами и их значениями:
- ls -l: покажет содержимое внутри директории с правами;
- file <name>: показывает тип файла и формат его содержимого;
- stat <name>: показывает полную информацию о файле.

1.3) Создание Git-репозитория, а также создание отдельного репозитория на GitHub.

2.1) Мы научились строить файловую структуру.

Разобрались с командами и их значениями:
- touch: создать файл;
- nano: создать файл и начать его редактировать в безопасном режиме.

2.2) Мы научились перемещать данные внутри системы.

Разобрались с командами и их значениями:

- rm: удалить файл;
- mkdir: создать директорию;
- rmdir: удалить пустую директорию.

## Блок 3: Поиск файлов и информации внутри системы

3.1) Мы научились пользоваться командой find.
- find: показывает путь до файла/директории по заданным условиям.

3.2) Мы научились пользоваться which и whereis, поняли их разницу:
- which: показывает путь до расположения исполняемого файла команды через PATH;
- whereis: показывает расположение исполняемого файла команды и связанных файлов с 
этой командой (мануалы и другие связанные файлы).

3.3) Мы научились пользоваться командой locate:
- locate: позволяет найти путь до файла/директории по заданной базе данных.

## Блок 4: Пользователи и права

4.1) Мы научились разбираться в ошибка запуска файлов, а затем исправлять это 
через команду chmod.
- chmod: изменение прав использования у файлов.

4.2) Мы научились разумно пользоваться командой chmod:
- chmod 755. Рут = 7: читать (4) + редактировать (2) + запускать (1). Пользователи
группы = 5: читать (4) + запускать (1). Все остальные = 5: читать (4) + запускать(1)
- выдавая 777, мы рискуем безопасностью информации, при выдаче такого доступа файлу.

4.3) Мы научились создавать пользователя и делать его владельцем:
- id: показывает информацию о пользователе (UID GID groups);
- groups: показывает информацию о группах, в которых состоит пользователь;
- adduser: создает нового пользователя в системе;
- addgroup: создает новую группу в системе;
- chown: меняет владельца(и группу) файла;
- chgrp: меняет группу у файла/директории.

Выполнили коммит по этому блоку.
